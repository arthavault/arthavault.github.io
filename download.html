Why Google Play Protect may show a warning. ARTHAVAULT is not on Google Play. It is a new app from a new, independent developer, and Play Protect warns about apps from developers it has not seen before. On the developer's phone, earlier builds showed a red "Harmful app blocked" message. The current version shows "Play Protect hasn't seen an app from this developer before. It may be unsafe." This yellow message is not a malware detection: it does not say that anything harmful was found in the app, only that Google does not know this developer yet. The reason for the earlier block is not known, and the developer has filed an appeal with Google; there is no result yet. What the app does: it has no internet permission, so it cannot send your data anywhere; your records stay on your phone; there are no ads and no accounts. Only install if you trust the developer, and compare the SHA-256 shown below with the file you downloaded.

How to install

  1. Download the APK on your Android phone with the button above. If asked, allow your browser or Files app to install apps.
  2. Open the downloaded file and press Install.
  3. If Google Play Protect shows a warning, read the note above. If you trust the developer and want to continue, tap Install anyway on the warning screen (shown below). The words and position can differ a little on different phones. Do not turn Play Protect off; you only need to continue with this one app.
  4. Open ARTHAVAULT and accept the Terms to start.
  5. Moving from an older version: the current version cannot be installed over 2.3.0 or any earlier version. Make a Backup in Settings first, uninstall the old app, install this version, then Restore. The backup does not contain your PIN or security questions, so set those again. Versions 2.4.0 and later install directly over each other.
