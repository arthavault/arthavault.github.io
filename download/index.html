How to install

  1. Download the APK on your Android phone.
  2. Open it. If asked, allow your browser or Files app to install apps.
  3. If Play Protect warns you, read the notice above and decide for yourself.
  4. Moving from an older version: the current version cannot be installed over 2.3.0 or any earlier version, including 2.1.1. Make a Backup in Settings first, uninstall the old app, install this version, then Restore. The backup does not contain your PIN or security questions, so set those again. Future updates signed with the same key install directly over this one.
