How to install

  1. Download the APK on your Android phone.
  2. Open it. If asked, allow your browser or Files app to install apps.
  3. If Play Protect warns you, read the notice above and decide for yourself.
  4. Moving between versions: versions 1.0 to 2.1.0 use one signing key and update over each other. Version 2.1.1 uses a new key, so it cannot be installed over them. Make a Backup in Settings first, uninstall the old app, install 2.1.1, then Restore. The backup does not contain your PIN or security questions, so set those again.
