Download latest All versions

What it does

Accounts and transactions

Cash, bank, wallet and investment accounts with income, expense and transfer records.

Investments

Track holdings, purchases and profit or loss.

PIN and fingerprint

Lock the app with a PIN and, if your phone supports it, your fingerprint. Forgot PIN uses your security questions.

English and Nepali

Switch language in Settings. A guided app tour is included.

Built-in calculator

Quick sums beside the + button, and send the result into a new entry.

Backup and restore

Save a backup file, optionally password protected, and restore it any time.

Privacy

The app has no internet permission. It cannot send your records anywhere. Backups are files you save yourself. The only permissions are fingerprint (optional). Data is stored on the phone and is not encrypted at rest, so use the PIN and keep your phone locked.

Download

Please read. Google Play Protect may show "Harmful app blocked" for this app because it is new and is not distributed through Google Play. The developer has filed an appeal with Google. VirusTotal scans of v2.1.1 show no detections from the antivirus engines that could scan it (a few engines could not process the file type). That is not a guarantee of safety. Only install if you trust the developer, and check the file's SHA-256 below after downloading.

How to install

  1. Download the APK on your Android phone.
  2. Open it. If asked, allow your browser or Files app to install apps.
  3. If Play Protect warns you, read the notice above and decide for yourself.
  4. Moving between versions: versions 1.0 to 2.1.0 use one signing key and update over each other. Version 2.1.1 uses a new key, so it cannot be installed over them. First open the old app, go to Settings and make a Backup. Uninstall the old app, install 2.1.1, then Restore. The backup does not contain your PIN or security questions, so set those again.
